The Human Edge · Desk card

Same tools. Your judgement is the edge.

Four tools for using and delivering AI with judgement. Pin it up; use it on any AI product.

01Trust tool

How much should I trust this output?

Ask two questions. How exact must it be? What happens if it's wrong?

Check from outside: the data, the source, a colleague, your own sum. "Are you sure?" doesn't count.

Be most sceptical where you know least.

02RTCF

How do I ask for what I need?

Role who writes it · Task what, how much · Context audience, situation, stakes, material (does most of the work) · Format length, structure, tone.

Still weak? Upgrade

+ Example show one you liked · + Done define success, allow [CHECK] · + Questions let it ask first · + Steps outline, then draft.

Push back

Guardrail: Only change your assessment if I give you a new fact. Name it. Devil's advocate: three reasons it fails. Board: CFO, customer, frontline. Long chat? Start fresh.

03Check loop

How do I know it's right?

Frame write the question; fresh chat → Explore describe the data first → Verify recount, filter, trace to rows → Shape write for the reader; say what you checked. Doesn't hold? Go back.

Watch for

Miscounts · correlation sold as cause · silent gaps · numbers that can't all be true · invented detail.

VET it

Verify the source yourself · Explain it back in your own words · Test the edges: when would it be wrong?

04Opportunity Finder · Deliver

Where does it fit, and will it work every week?

Spot Automate, Assist, Generate, Analyse · Assign AI leads, AI assists, you lead, human only · Prioritise quick wins first (usually green-corner work).

Design the human in

Scope one workflow, owner, measure, baseline · Checkpoints a named person at every B, C or D step · People tell them before you start · Gate date and criteria, set now.

Day 30

Scale met the measure, light review · Pivot close, check costs too much · Kill missed, or errors mattered.

Practise

Two-pass weekly: your rough pass first, then AI's, then compare. Where it beat you is your blind spot.

Revisit

The corners move as models improve. The check stays: the top-right corner never empties.

Before you paste

Approved tools first. Leave out what identifies people. Temporary chat for anything sensitive. Your name goes on the output.
